# Contributing Guidelines

Thank you for contributing to Mini Container Runtime.

## Development Workflow

1. Clone the repository.
2. Create a feature branch.
3. Implement your changes.
4. Test your implementation.
5. Commit your changes.
6. Push your branch.
7. Open a Pull Request to main.

## Branch Naming

- feature/feature-name
- fix/bug-description
- docs/documentation-update
- test/test-description

## Commit Convention

Use descriptive commit messages:

- feat: add PID namespace support
- fix: resolve process cleanup issue
- docs: update project documentation
- test: add namespace tests
- refactor: improve container initialization

## Pull Requests

- Keep changes focused.
- Explain what you changed.
- Include relevant testing information.
- Avoid committing generated binaries.
